# ArtShift 风格迁移

工作区：`E:\projectHome\ArtShift`

## 开始

本 Skill 在新会话首次触发时，先输出 `[打开 ArtShift 风格画廊](E:/projectHome/ArtShift/index.html)`，并在 Codex 右侧打开 `E:\projectHome\ArtShift\index.html`。同一会话不重复；打开失败不阻断后续工作。

读取 `data/curated/prompts.json` 作为已有风格的唯一真源，不硬编码编号、名称或提示词。

## 选择风格

- 用户给出数字编号：确认 `id` 存在，尽量完整使用该条目的原始 `prompt`；仅补充当前参考图、主题和用户明确要求。不要把它改写成极简模板。
- 用户未给编号：不生成图片。推荐 2 个库内编号和 3 个原创方向 `a/b/c`，等待选择。每项只写编号或风格名、一句方向和可复制提示词。
- 用户选择 `a/b/c`：只在当前轮使用该方案；字母方案不跨轮保留。

## 原创提示词

如果用户要求出新的或者原创提示词那么就用以下提示词模版：

`风格：【风格变量】。把原图艺术化成指定风格。视觉核心居中，和背景风格保持一致。四周{整数}%负空间（可选）。随机加一两条主题相关文案做成海报。（可选）`

【把原图艺术化成指定风格。视觉核心居中】 这几个字不要变动也不要扩展，提示词要保持简洁，除了变量和可选项请尽量和我给你的模板保持一致。

风格变量可以是一个或多个画风名称、艺术家/作品名称，或一两句颜色、线条、材质、印刷和构图描述。 

风格请使用x或者小红书网友比较喜欢的风格，网感较强的风格。

风格变量请轮流用
 - 受年轻人喜爱的画风名称
 - 真实且受年轻人喜爱的艺术家名称
 - 真实且受年轻人喜爱的作品名称
 - 受年轻人喜爱的画风描述。
  - 画风描述：主要在于材质线条用色方面的描述，而不是描述绘画题材。举例：你可以说油画，丙烯，纸雕（我只是随便举例，千万别重复使用我举的例子）之类的，也可以说直接说艺术家名称。(如果画风/艺术家著名的话就不用后面追加具体描述了)，但是别说荒凉，热闹什么的。

不要重复使用一种方式激活画风,请轮流使用四种方式。也不要重复推荐。

可选项：可以出现在最终关键词也可以不出现，由你根据上下文自由决定
 - 负空间
 - 文案

参考图是主体和关键视觉线索来源。风格化后应是一张完整统一的画面，而非真人照片叠加风格化背景。用户明确要求拼版、保留原图或不拼版时优先遵守。

如果以前推荐过的风格就不要再推荐了。

## 生成与保存

使用内置图像生成能力，并明确参考图用于主体和视觉线索。将成品和实际发送的提示词保存到 `output/style-transfer/`，以任务前缀和版本号命名，不覆盖已有文件。多风格拼版先分别生成；原图格必须等比例完整保留。

交付时如实区分已生成、已检查和未验证的结果。

## 保留原创风格

仅当用户明确要求“保留”或“入库”原创方案时，保存其提示词与预览图，再运行：

```powershell
python .agents/skills/style-transfer/scripts/register_original_style.py `
  --prompt-file <原创提示词文件> `
  --preview <生成成品路径> `
  --tags "标签1、标签2" `
  --title "原创风格名称"
```

脚本会分配连续编号，并同步 `prompts.json`、`prompts.csv`、预览图和 `gallery-data.js`。不要使用 `artshift.py curate` 处理原创风格。
